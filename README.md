# Ryan Gosling — portfolio

Учебный сайт-портфолио о Райане Гослинге, созданный на занятии и опубликованный с открытым исходным кодом. Делюсь этой небольшой творческой работой — её можно изучать, запускать локально, изменять и использовать как основу для собственных экспериментов с веб-дизайном.

## Что внутри

- выразительная одностраничная композиция в редакционном стиле;
- избранные роли и основные этапы карьеры Райана Гослинга;
- интерактивная музыкальная секция;
- плавные анимации с учётом системной настройки уменьшения движения;
- полноценная адаптивная мобильная версия для смартфонов и планшетов.

## Технологии

Проект собран на стандартном веб-стеке без фреймворков:

- HTML;
- CSS;
- JavaScript.

## Локальный запуск

```bash
python3 -m http.server 4173
```

После запуска откройте `http://127.0.0.1:4173`.
